Every time you write a great prompt and then lose it in a chat history, you pay for the same work twice. A prompt library fixes that, and it takes less setup than you'd think.

## Where to keep it

Anywhere you'll actually open: a notes app, a shared doc or a simple spreadsheet. Fancy tools can wait.

## What goes in each entry

- **Name:** "Weekly status update"
- **When to use it:** one line
- **The prompt**, with brackets for the parts that change
- **Notes:** what worked, what didn't, the date you last tested it

## A template to copy

```
You are a [role].
Task: [what to do].
Context: [who it's for and why].
Format: [bullets, table, email, etc.].
Constraints: [length, tone, things to avoid].

Input:
[paste here]
```

## Habits that keep it useful

- Save a prompt the second time you use it, not the tenth.
- Fix the template when a result disappoints you, and note what you changed.
- Group prompts by job (writing, analysis, planning) rather than by tool.
- Share the best ones with teammates. Everyone gets better faster.

## Try it today

Find the three prompts you've used most this month. Clean each one into the template above and save them in one place.
