The biggest password problem isn't weak passwords. It's reused ones. When one site gets breached, attackers try the same email and password everywhere else. A password manager ends that.

## What it does

It creates a long, random, unique password for every account, stores them in an encrypted vault, and fills them in for you. You remember one strong passphrase and the manager remembers the rest.

## "Isn't that all my eggs in one basket?"

Fair question. But the vault is encrypted, and with multi-factor authentication turned on, it's much safer than the alternative, which is a handful of reused passwords. Managers also check the website address before autofilling, so they won't hand your login to a lookalike site.

## Getting set up

1. Choose a well-reviewed manager from a reputable company.
2. Create a master passphrase: four or five random words, easy for you to type and long enough to be hard to guess.
3. Turn on multi-factor authentication for the manager itself.
4. Save your recovery information somewhere safe and offline.
5. Start with your most important accounts: email, banking and anything that holds payment details. Change those passwords first.

## Don't try to do it all at once

Each time you log in somewhere, let the manager capture it and upgrade the password. In a few weeks most of your accounts will be covered.

## Try it today

Install a manager, set the passphrase, and change the password on your main email account. That one account is the key to resetting everything else.
